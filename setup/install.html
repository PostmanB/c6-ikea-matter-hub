C6 IKEA HUB · FIRST INSTALLATION

a new ESP.

Install experimental Wi-Fi/HomeKit firmware on an ESP32-C6-DevKitC-1 with 8 MB flash. Then pair your own IKEA devices.

This development build has compiled successfully. Wi-Fi/Thread coexistence, Apple Home pairing and power-cycle time recovery still need hardware validation.

Already running this hub? Go to device setup →

01

Prepare the board

Open this page in desktop Chrome or Edge. Connect the ESP’s UART / USB-UART socket with a data cable. Close other serial monitors.

If Windows does not show its USB-UART port, install the CP210x driver linked in the setup guide. If connection fails, hold BOOT, tap RESET, then release BOOT and try again.

02

Install firmware

First installation erases the board, including any saved network, device pairings and other firmware. Use this only on the new board you want to turn into a hub.

Use desktop Chrome or Edge with Web Serial. Open this page over HTTPS or localhost.

The installer loads ESP Web Tools from unpkg.com and firmware from this site. Device pairing happens separately over USB. If the install button does not respond, check your Internet connection or use the Windows flashing script.

03

Pair your devices

After installation completes, close the installer, unplug the cable and reconnect to the ESP’s native USB socket. Open device setup and tap RESET once if needed.
